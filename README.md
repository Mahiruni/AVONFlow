# AVONFlow

AVONFlow is a responsive, conversion-focused AI video and image generation website built with React and Vite. It includes four linked routes:

- `/` — product landing page
- `/pricing` — plans, currency switcher, comparison table, and FAQ
- `/about` — platform and extension-access explanation
- `/earn` — referral rewards, earnings examples, wallet, and withdrawals

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run test:sites
```

The deployable static bundle is generated in `dist/`. The included worker provides SPA route fallback support for direct visits to `/pricing`, `/about`, and `/earn`.

## Deployment

Deploy the `dist/` directory to any static host with SPA fallback support, or use the included worker bundle generated by `npm run build`.

## Integration notes

The signup/login dialog, support chat, currency switch, referral copy state, and FAQs are interactive frontend prototypes. Connect authentication, checkout, analytics, live support, referral data, and verified creator statistics before a public production launch.
